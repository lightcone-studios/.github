## Captain's Card

**Does:** <!-- One sentence. The change and why. -->

**Touches:** <!-- Files, systems, services affected. -->

**Could break:** <!-- Worst realistic failure if this is wrong. -->

**Proof:** <!-- Test output, verification run, or exactly how this was checked. "Should work" is not proof. -->

**Could not see:** <!-- What this change's verification cannot observe. Name the blind spots. -->

**Undo:** <!-- How to revert if it goes sideways. -->

**Rail:** <!-- GREEN (routine, small, reversible) / AMBER (feature, large, or judgment needed) / RED (security-adjacent, secrets, infrastructure). -->

**Your call:** <!-- What the reviewer is actually deciding. -->
