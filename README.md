# .github

Organization-wide defaults for lightcone-studios repositories.

| File | Role |
|---|---|
| `profile/README.md` | The organization's public profile page |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template (the Captain's Card) for every repo without its own |
| `CONTRIBUTING.md` | Default contributing guide for every repo without its own |
| `SECURITY.md` | Default security policy for every repo without its own |

This repository must be public for GitHub to apply these defaults across the organization. A repository that defines its own version of a file overrides the default here.
