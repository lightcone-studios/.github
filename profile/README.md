# Lightcone Studios

Independent software studio in Seattle, WA.

We build community infrastructure, local-first tools, and agent systems for the Pacific Northwest, with a working method that treats verification as the product: every merge rides a protected rail, every claim of "done" ships with its proof.

## What we work on

- **Builders Index.** A hyperlocal directory connecting Puget Sound homeowners with vetted contractors.
- **AI Northwest.** Tooling, media, and event infrastructure for the PNW AI community.
- **Agent operations.** Discipline, telemetry, and security practice for running AI agents as a working crew.

## How we ship

Small reversible changes, pull requests on every branch, review before merge, verification before claim. Our contributing guide and PR template in this repository apply across the organization.
